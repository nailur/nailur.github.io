Bandwidth Data Keluar (Supabase Egress — Limit Gratis: 5 GB / Bulan)

Egress adalah total trafik data keluar dari server ke aplikasi kasir. Limit 5 GB direset otomatis setiap tanggal siklus tagihan bulanan.

Mengapa Egress NTPOS selalu rendah? Karena aplikasi ini menggunakan teknologi PWA Offline Cache, kasir tidak perlu mendownload ulang aset/gambar dari server setiap kali buka halaman, menjaga pemakaian Egress tetap < 0.5% (20-40 MB/bulan).

Panduan Kritis: Kapan Harus Upgrade atau Migrasi Server?

KONDISI AMAN (Free Plan)

Selama ukuran Database < 400 MB dan Egress < 4 GB/bulan, Anda TIDAK PERLU mengeluarkan biaya langganan apa pun. Kasir dapat berjalan 100% gratis selamanya.

TINDAKAN HEMAT (Tanpa Upgrade)

Jika suatu saat database mencapai 400–450 MB (estimasi >5-10 tahun lagi), cukup unduh (export) transaksi lawas (>2 tahun) dan hapus dari database untuk meluangkan kapasitas gratis tanpa upgrade.

WAKTU UPGRADE KE PRO ($25/bln)

Hanya diperlukan jika outlet Anda berkembang super masif dengan >2.000 transaksi setiap hari, atau membutuhkan Egress melebihi 5 GB. Cukup aktifkan Supabase Pro Plan tanpa perlu memindahkan kode atau server.
